\textbf{Research Highlights} \\
\vspace{1em}
\textbf{Identifying Rational Types in Unknown Environments under an Indirect Dynamic Mechanism} \\
Humberto Bernal
\end{center}

\vspace{2em}

\begin{itemize}
    \item A dynamic indirect mechanism is designed for environments with observational pooling.
    \item The MDG process models execution errors under maximum entropy constraints.
    \item Bayesian learning is shown to converge almost surely to the true rational type.
    \item The perfect Bayesian equilibrium is shown to guarantee sequential implementability.
    \item Deep learning networks approximate the captor value function to solve the game.
\end{itemize}
