Humberto Bernal

\vspace{2em}

\begin{itemize}
    \item Se diseña un mecanismo dinámico indirecto para entornos con agregación observacional.
    \item El proceso MDG modela errores de ejecución bajo restricciones de entropía máxima.
    \item Se demuestra que el aprendizaje bayesiano converge casi seguramente al tipo real.
    \item Se demuestra que el equilibrio bayesiano perfecto garantiza implementabilidad secuencial.
    \item Redes de aprendizaje profundo aproximan la función de valor para resolver el juego.
\end{itemize}
